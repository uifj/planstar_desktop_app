## 状态口径

- `PROPOSED`：问题已核实，尚未修复或尚未完成完整验收。
- 已在当前分支修复的子项应在对应 ADR 中写明真实 commit 与验证范围，不得继续笼统标为缺失。
- macOS 运行改动只覆盖启动阻塞，不改变业务契约、存储格式或依赖方向。
