ADR-0017 至 ADR-0018 均为 `PROPOSED`，**仅登记，暂不修复业务逻辑**；ADR-0016 的

## 状态口径

- `PROPOSED`：问题已核实，尚未修复或尚未完成完整验收。
- `ACCEPTED`：决策已实现并完成记录的验收；修复 commit 必须回填真实提交号与验证范围。
- 已在当前分支修复的子项应在对应 ADR 中写明真实 commit 与验证范围，不得继续笼统标为缺失。
- macOS 运行改动保持业务契约、存储格式与依赖方向不变。
