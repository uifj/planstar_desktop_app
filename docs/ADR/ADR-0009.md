# ADR-0009: 迁移 material_ui 独立包，清理 Flutter 3.50 弃用面

- **状态**: IMPLEMENTED（待提交）
- **分类**: DEBT
- **优先级**: P2
- **影响维度**: 认知障碍 / 评估阻断
- **日期**: 2026-11-18
- **来源**: Flutter 3.50 官方公告核实 + 项目 analyze/import 面核实
- **修复 commit**: —

## 背景（Context）

1. **Flutter 3.50 正式弃用耦合库**（官方博客 2026-11-11「Decoupled design
   packages」）：`package:flutter/material.dart` 与
   `package:flutter/cupertino.dart` 及其 flutter_localizations 代理被弃用；
   新项目默认 `package:material_ui`；官方迁移命令
   `dart fix --apply --code=migrate_design_widgets`。
2. **项目现状**：lib/ 下 **25 个文件** import `package:flutter/material.dart`
   （grep 核实，含 app/shell、全部 feature presentation、windows 两个入口）；
   `flutter analyze` 现存 **53 条 info**，主体即 material.dart 弃用提示。
   AGENTS.md §6 门禁为 0 error/0 warning，info 未阻断但持续掩盖新增告警
   （评估阻断维度）。
3. **material_ui 已在依赖图内**：pubspec.lock:752-759 解析 material_ui 1.11.1
   （当前为 transitive），无需新增下载面，只需提升为直接依赖。
4. `.agents/dart-editing.md` 的收尾门禁原文是 `--fatal-infos`；当前因这 53 条
   info 无法执行该强度，AGENTS.md §6 暂定为 0 error/0 warning。

## 决策（Decision）

1. pubspec.yaml 显式声明 `material_ui`（版本以 lock 已解析的 1.11.x 为基线）。
2. 运行 `dart fix --apply --code=migrate_design_widgets` 批量迁移 import
   与本地化代理；逐文件复核 fix 未覆盖处（自定义 ThemeExtension 与
   core_design_system 的 AppTheme 集成点重点目视）。
3. `uses-material-design: true` 保留（DatePicker 等内置控件内部图标仍需要，
   AGENTS.md §6 已注明）；业务图标继续 lucide_icons_flutter，不随迁移换图标。
4. 迁移完成后将分析门禁收紧为 `dart analyze --fatal-infos`（对齐
   .agents/dart-editing.md），并同步更新 AGENTS.md §6 表述。
5. 与性能/架构改造**错峰提交**：纯 import 面变更单独成 commit
   （type=refactor，scope=ui），避免与行为改造混在同一 diff 里难审。

候选取舍：
- 「压制弃用告警（ignore 规则）」：掩盖真实迁移需求，违反 AGENTS.md §7
  不得靠白名单变绿的精神，弃用。
- 「等 material.dart 移除再迁」：移除是未来必然（官方已声明），越晚迁
  与框架行为差异累积越大，且当前 fix 工具成熟，弃用。

## 后果（Consequences）

- **正面**: 53 条 info 清零，--fatal-infos 门禁可执行，新增告警不再被淹没；
  与官方新项目形态对齐，后续 SDK 升级无弃用断崖。
- **负面/风险**: material_ui 与 SDK 内 material 存在细微行为差异的可能
  （官方迁移指南列有 breaking changes），须全量 widget 测试 + 目视回归；
  25 文件 diff 面大，审查成本高（以独立 commit 缓解）。
- **中性**: core_design_system 令牌层不变，颜色/字体单一来源不受影响。

## 验证（Verification）

- `dart analyze --fatal-infos` 0 告警；`flutter analyze` 0 error/0 warning。
- 根工程 + core + 设计系统测试全绿；`flutter build windows --debug` 通过。
- grep 断言：lib/ 下 `package:flutter/material.dart` import 零残留。
- 目视回归：主窗口各页、桌面组件、托盘菜单、DatePicker/对话框等内置控件。

## 实施记录（2026-11-19）

### 落地内容

- pubspec.yaml 显式声明 `material_ui: ^1.11.1`（lock 已解析 1.11.1，由 transitive
  提升为直接依赖）；`flutter pub get` 仅 "Changed 1 dependency"，win32 5.15.0 /
  win32_registry 2.1.0 / file_picker 11.0.3 / flutter_secure_storage 10.3.4 不变。
- `dart fix --apply --code=migrate_design_widgets`：**30 fixes / 30 files**，
  纯 import 面替换 `package:flutter/material.dart` → `package:material_ui/material_ui.dart`
  （含 app/shell、全部 feature presentation、windows 两入口、shared/widgets/common.dart）。
  fix 同时为 core_design_system 补 `material_ui: any` 直接依赖（missing_dependency
  自动修复，workspace 统一解析到 1.11.1）并把其 SDK 约束对齐 ^3.14.0 / >=3.50.0。
- 目视复核 fix 覆盖：core_design_system 的 app_theme.dart / semantic_colors.dart /
  typography.dart 仅 import 行替换，`ThemeExtension`/`AppTheme` 集成点由 material_ui
  同名导出，令牌层逻辑零改动；theme_test.dart 同步换 import。
- 门禁收紧（决策 4）：另跑 `dart fix --apply --code=prefer_initializing_formals`
  清零历史遗留的 23 条 initializing-formal info（11 文件，私有命名初始化形参
  `required this._store` 等，Dart 3.14 外部名仍去下划线，调用方 `store:` 不变）；
  AGENTS.md §6 门禁表述更新为 `dart analyze --fatal-infos` 0 告警，并新增
  「业务 widget 统一 import material_ui，不用已弃用 flutter/material.dart」约定。
- `uses-material-design: true` 保留、业务图标继续 lucide_icons_flutter（决策 3）。

### 验证

- grep 断言：lib/ 与 packages/infras/*/lib/ 下 `package:flutter/material.dart`
  与 `package:flutter/cupertino.dart` import **零残留**。
- `dart analyze --fatal-infos`：**No issues found!**（29 条 deprecated_member_use
  + 23 条 prefer_initializing_formals 全清零）；`flutter analyze` 0 error / 0 warning。
- 测试全绿：根工程 75、core 154、设计系统 14。
- `flutter build windows --debug` 通过（98.7s；MSB8028 共享中间目录 warning 为
  既有插件工程噪声，非错误）。
- 运行时冒烟 + `verify_desktop_widget.ps1`：健康签名与 ADR-0007 基线一致——
  overlay style=0x94000000 ex=0x80 region=3 regionBox=280,0→1280,1016，
  (60,60)=PASS-THROUGH、(300,300)/(448,378)/(900,300)=HIT；主窗口
  style=0x14CF0000 ex=0x100 rect=193,79,1320x860；两 engine 均日志
  「本地通知插件初始化完成」、进程存活、无异常。
  注：首次启动 12s 内进程退出（仅主 engine 初始化日志），重跑即健康——与
  ADR-0010 登记的 Intel D3D11/GLES 驱动间歇 AV 环境风险一致，A/B 已证与 Dart
  接线无关，非本次迁移回归。
- 目视回归局限：自动化冒烟覆盖启动链/桌面 overlay 命中区域/双 engine 初始化；
  主窗口各页、托盘菜单、DatePicker/对话框的逐页人工目视未在本轮执行，
  留待用户运行 `flutter run -d windows` 复核（material_ui 与 SDK 内 material
  的细微行为差异风险见「后果」）。
