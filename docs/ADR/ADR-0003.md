# ADR-0003: 拆分 core/ports.dart 按能力域分组，持久化键名映射反转到 feature 侧

- **状态**: IMPLEMENTED（待提交）
- **分类**: ARC
- **优先级**: P1
- **影响维度**: 认知障碍 / 上下文膨胀 / 幻觉源
- **日期**: 2026-11-18
- **来源**: 全量审计（docs/arch_optimize.txt A1）+ 逐条代码核实
- **修复 commit**: —

## 背景（Context）

`lib/core/ports.dart` 共 **381 行**（审计称约 376），塞了 **12 个端口 +
6 个 DTO + 2 个枚举 + 1 个具体类 + 1 个顶层函数**（审计称 5 DTO/1 枚举，已修正）：

- 端口：StorageReloader:14、CrossEngineSync:59、Clock:66、SoundGateway:97、
  NotificationGateway:122、WindowGateway:167、TrayGateway:221、
  MultiWindowGateway:235、AutoStartGateway:262、WallpaperImageGateway:295、
  DesktopWallpaperGateway:340、FileGateway:368。
- DTO：DataChange:23、ScheduledReminder:102、WindowRect:136、
  MultiWindowCommand:228、DesktopMetrics:269、DesktopCardRect:316；
  具体类 SystemClock:70；枚举 SoundTone:78、TrayAction:204。

三处具体越界（依赖方向违反 AGENTS.md §3「Domain 不依赖基础设施细节」）：

1. **`reloadTargetFor(String key)`（:41-53，审计称约 44 行）**：core 端口层
   硬编码前缀 `planstar.calendar.` 与 7 个具体持久化键
   （settings/notes/countdowns/subscriptions/timetables/history/desktop.card），
   映射 8 个 feature 重载分组名。**加任何新 feature 都必须回来改 core**——
   这是「越晚改越贵」的债，每加一个 feature 都在加深它。
2. **`SoundTone.asset`（:78-95）**：`'audio/audio_ding.mp3'` 等是 Flutter
   asset bundle 路径，属基础设施细节；core 只该有语义（ding/littleStar）。
   另 `dong`（:83）与 `ding`（:80）指向同一文件，疑似复制粘贴漏改（待确认）。
3. **`TrayAction`（:204-219）**：14 个成员（审计称「14 个导航目标」不准确——
   show/hide/toggle/sync/refreshWallpaper/exit 等是窗口/动作指令，
   settings/timetable/notes/about 等才是导航）。core 在枚举 UI 目的地与窗口指令。

## 决策（Decision）

1. **按能力域拆分为 `lib/core/ports/` 目录**，DTO 与各自端口同居：
   - `ports/storage.dart`：StorageReloader、CrossEngineSync、DataChange、
     重载目标注册表（见第 2 条）
   - `ports/clock.dart`：Clock、SystemClock
   - `ports/sound.dart`：SoundGateway、SoundTone（仅语义，见第 3 条）
   - `ports/notification.dart`：NotificationGateway、ScheduledReminder
   - `ports/window.dart`：WindowGateway、WindowRect、MultiWindowGateway、
     MultiWindowCommand
   - `ports/tray.dart`：TrayGateway、TrayAction
   - `ports/desktop.dart`：AutoStartGateway、DesktopMetrics、DesktopCardRect、
     WallpaperImageGateway、DesktopWallpaperGateway
   - `ports/file.dart`：FileGateway
   `ports.dart` 保留为纯 export 汇总入口（现有 import 路径不破，属门面而非
   兼容垫片）；新代码按域 import。
2. **键名映射反转**：core 只定义注册表端口（key/前缀 → 重载分组名的注册与
   查询接口），各 feature 的 infrastructure 声明自己的键名映射常量，
   组合根 bootstrap.dart 聚合注册。`reloadTargetFor` 顶层函数删除，
   data_hub.dart 的广播分发改查注册表。**lib/core 下不再出现任何
   `planstar.*` 持久化键字面量**。
3. **SoundTone 去 asset 化**：枚举保留语义与中文标签，asset 路径映射移到
   infrastructure 的 AudioPlayersSoundGateway 实现内。dong/ding 同文件问题
   **保持现行为**并登记为待产品确认项（不擅自改音色）。
4. **TrayAction 整体移入 ports/tray.dart，成员契约不变**（14 个成员是托盘
   菜单的既有契约，拆文件不等于改契约）。菜单项按 feature 贡献的
   contributor 模式列为远期可选（与 ADR-0004 思路一致），本次不做。

候选取舍：
- 「只拆文件不反转键名」：治标不治本，core 仍被每个新 feature 穿透，弃用。
- 「键名映射放 bootstrap 集中配置」：比现状好，但仍是集中式清单，
  feature 自治不彻底；注册表模式让 feature 自带映射，bootstrap 只聚合。

涉及公共端口契约与目录结构调整，**实施前按 AGENTS.md §3 先经用户确认**。

## 后果（Consequences）

- **正面**: 新 feature 不再触碰 core；端口按域阅读，单文件上下文从 381 行
  降到 ≤100 行；core 不再泄漏 asset 路径与持久化键名两类基础设施细节。
- **负面/风险**: 一次性 import 面调整（ports.dart 门面兜底，风险低）；
  注册表漏注册会导致跨 engine 重载静默失效——须有「每个存储键都有注册项」
  的守卫测试。
- **中性**: TrayAction/SoundTone 契约不变，托盘与声音行为零变化。

## 验证（Verification）

- grep 断言：`lib/core/` 下无 `planstar\.` 键字面量、无 `audio/` asset 路径。
- 守卫测试：遍历全部 feature 存储键，断言注册表查询均非 null。
- `flutter analyze` 0 error/0 warning；根工程 + core + 设计系统测试全绿。
- 跨 engine 重载冒烟：主窗口改设置 → 桌面组件重载分组命中（行为同旧版）。

## 实施记录（2026-11-18）

- **拆分**：ports.dart 381 行 → `lib/core/ports/` 8 个域文件
  （storage/clock/sound/notification/window/tray/desktop/file，最大
  desktop.dart 约 130 行），ports.dart 保留为纯 export 门面，现有 import
  零改动。DesktopWallpaperGateway 对 WindowRect 的引用改为域间 import。
- **键名反转**：`ReloadTargetRegistry`（精确键 + 前缀两级，精确优先）落在
  ports/storage.dart；8 个 feature 各自声明键常量与
  `register*ReloadTargets`（calendar 前缀注册，其余精确键；桌面卡片位置键
  从 _DesktopWidgetAppState 私有常量提为 desktop_widget_app.dart 顶层
  `desktopCardPositionKey`）；聚合点 lib/bootstrap/reload_targets.dart 的
  `buildReloadTargetRegistry()` 纯函数，bootstrap 注入
  `reloadTargetRegistryProvider`，CrossEngineSyncController._reloadFor
  改查注册表。顶层 `reloadTargetFor` 删除。
- **SoundTone 去 asset 化**：枚举只剩 label + fromName；asset 映射移入
  AudioPlayersSoundGateway._toneAssets，dong/ding 同文件保持现行为并注释
  登记待产品确认。
- **TrayAction**：整体移入 ports/tray.dart，14 成员契约不变。
- **验证**：grep 断言通过——lib/core/ 下无 `planstar.` 键字面量、无
  `audio/` 路径；全仓无 reloadTargetFor/tone.asset 残留。守卫测试
  （data_hub_test.dart「每个 feature 存储键都有注册项」）以键常量断言
  9 键全命中 + 未知键 null。`flutter analyze` 0 error/0 warning
  （53 info 基线）；根 51 / core 154 / 设计系统 14 全绿；
  `flutter build windows --debug` 通过；运行时冒烟：启动 exe → tasklist
  核实主 engine + 桌面 overlay 两进程存活 → taskkill 清理完毕。
- **顺带修复**：dart format tall 风格把 desktop_widget_app.dart 一处
  单行 if 拆行触发 curly_braces lint，已加块括号。
