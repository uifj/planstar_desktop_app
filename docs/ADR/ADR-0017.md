# ADR-0017: 跨端共享语义与用户可见展示存在不一致

- **状态**: PROPOSED
- **分类**: DEF
- **优先级**: P1
- **影响维度**: 生产功能 / 幻觉源
- **日期**: 2026-11-24
- **来源**: 跨仓库源码对照审计
- **修复 commit**: —

> 仅登记，暂不修改共享包、界面或本地化实现。

## 背景（Context）

1. 移动端与桌面端的 `ValueObject` 都递归比较 List/Map，但移动端 `hashCode` 仍使用 `Object.hashAll([runtimeType, ...props])`，嵌套集合采用 identity hash；桌面端已递归计算深哈希。相等的移动端值对象放入 Set/Map 时可能重复。证据：`../flutter_planstar_app/packages/infras/core/lib/src/domain/value_object.dart:38`、`packages/infras/core/lib/src/domain/value_object.dart:38-82`。
2. Next.js 的 `formatYuan` 默认添加 `¥`，`formatCompactYuan` 固定添加 `¥`，与“统一展示星币”的产品口径冲突。证据：`../planstar_kratos_server/planstar_frontend/planstar_web/packages/api-client/src/money.ts:24-32`。
3. 桌面端单次日历配色选择把同一颜色同时写入普通日期文字、背景和今日边框，可能造成普通日期文字与背景同色；今日文字使用 `onBrand`，不应笼统描述为全部文字同色。证据：`lib/features/settings/presentation/settings_page.dart:347-361`、`lib/windows/desktop_widget_app.dart:1390-1431`。
4. 桌面端根 `MaterialApp.router` 未配置 `localizationsDelegates` 或 `supportedLocales`，语言设置不能驱动界面本地化。证据：`lib/app/planstar_app.dart:40-58`。
5. 桌面端手动同步已会发起真实 POST 并接收服务端计数，但下载数据未持久化；“每个整点自动同步”仍只有开关状态，没有定时器或调度器。该缺陷与鉴权契约共同登记在 ADR-0014，避免重复修复。

## 决策（Decision）

- 暂不修改两端共享包或界面。
- 后续先明确“完全复用”边界：共享包行为应通过同一契约测试矩阵约束，而不是仅复制代码。
- 值对象相等/哈希必须在共享层形成明确不变量；两端当前 `readAll()` 都会重新解码元素，不再声明共享可变元素缺陷。
- 币种符号、日历颜色语义和语言切换以设计与产品口径为准；在口径确认前不猜测默认展示。
- 同步能力展示随 ADR-0014 的真实协议与调度实现一并收敛。

## 后果（Consequences）

- **正面**: 防止两端名为共享、实则语义分叉，提升 Set/Map、缓存读取和界面展示的可预测性。
- **负面/风险**: 统一共享包可能影响移动端与桌面端多个模块，需要双端回归。
- **中性**: 本记录不要求立即重构目录或引入新设计系统。

## 验证（Verification）

- 同一组嵌套 List/Map 值对象在移动端、桌面端分别验证 `==`、`hashCode`、Set 去重与 Map 查找，结果一致。
- 修改 `readAll()` 返回的元素后再次读取，断言缓存与底层存储未被意外修改；若选择共享只读语义，则用不可变类型在编译期约束。
- 对人民币、星币及大额紧凑格式分别截图/断言展示符号，确保符合产品契约。
- 选择浅色、深色和对比度不足的颜色后检查日历文字、背景、今日边框的可读性。
- 切换语言后验证根应用 locale、日期格式和静态文案同步变化，而不只是设置项持久化。
