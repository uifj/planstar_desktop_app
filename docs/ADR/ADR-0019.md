# ADR-0019: macOS 网络权限与发布产物覆盖不完整

- **状态**: PROPOSED
- **分类**: CFG
- **优先级**: P1
- **影响维度**: 生产功能 / 安全合规
- **日期**: 2026-11-24
- **来源**: 跨平台构建配置与 CI 发布链审计
- **修复 commit**: `e071161`（仅桌面端网络 entitlement 子项）

> 桌面端 macOS 启动任务所必需的最小 entitlement 调整已提交并记录运行证据；移动端、服务端发布链与真实业务网络验收仍保持开放，不以“能启动”替代验收。

## 背景（Context）

1. desktop legacy 分支原始 DebugProfile 与 Release entitlement 均启用 App Sandbox，但都缺少 `com.apple.security.network.client`。`e071161` 已为两者补上该权限，DebugProfile 保留 `network.server` 与 JIT，Release 不额外扩大权限；沙箱下真实出站请求仍未验收。证据：`macos/Runner/DebugProfile.entitlements`、`macos/Runner/Release.entitlements`。
2. 移动端 macOS Release entitlement 只声明 App Sandbox，同样缺少网络客户端权限。证据：`../flutter_planstar_app/macos/Runner/Release.entitlements`。
3. 服务端 Release workflow 只构建并推送 `planstar-api`，部署脚本却执行 `docker compose pull planstar-api admin admin-web` 并整体启动。Admin Go 服务与 Admin Web 不在同一发布构建链内，可能拉到旧镜像或不存在镜像。证据：`../planstar_kratos_server/.github/workflows/release.yml:24-26,66-74,180-181`。
4. 当前 `legacy-flutter-3.41.9` 分支的 Pub 约束为 Dart `^3.11.5`，本机保留 SDK 为 Flutter 3.41.9 / Dart 3.11.5；此前 master 的 Flutter 3.50.0 / Dart 3.14.0 基线不适用于本分支，下载的 3.50 SDK 已按用户要求删除。证据：`pubspec.yaml:6-7` 与本机 `flutter --version`。

## 决策（Decision）

- 暂不修改移动端 entitlement 或服务端 CI。
- 桌面端为完成本次 macOS 真实运行，仅允许添加 macOS 网络客户端 entitlement，并验证沙箱下实际出站请求；不得借机取消沙箱或扩大无关权限。
- 服务端发布修复应把 API、Admin、Admin Web 纳入同一版本标签与构建矩阵，部署前断言三个镜像存在且版本一致。
- 当前分支以 Flutter 3.41.9 / Dart 3.11.5 为唯一验证基线，不降低语言版本，不绕过 Pub 解析，也不混入 master 的依赖实现。

## 后果（Consequences）

- **正面**: 明确平台运行前置条件，避免错误地把网络失败归因为业务代码，并防止发布链只更新部分服务。
- **负面/风险**: 多镜像发布需要更长时间和明确回滚策略；网络 entitlement 扩大出站能力，需要限定真实业务用途。
- **中性**: SDK 安装在开发机，不改变项目依赖或用户数据格式。

## 验证（Verification）

- 已提交子项：`e071161` 为 DebugProfile 与 Release 添加 network client；macOS Debug 产物已构建并确认 entitlement，完整运行证据见 [ADR-0020](ADR-0020.md)。未单独构建 Profile，也未完成沙箱下真实出站验收。
- 待验收：检查 Debug、Profile、Release 构建的最终 entitlement，确认 sandbox 与 network client 均存在且无多余敏感权限。
- 待验收：在沙箱 macOS 进程中访问真实模式 API，验证 DNS、TLS 请求、非 2xx 与离线降级，而不只验证窗口出现。
- 待验收：对同一 Git tag 检查 GHCR 中 `planstar-api`、`admin`、`admin-web` 三个镜像 digest，部署日志必须显示对应版本。
- 已部分完成：在 Flutter 3.41.9 下执行根工作区依赖解析、`flutter analyze --no-pub --fatal-infos`、`flutter test --no-pub` 与 `flutter build macos --debug --no-pub`；干净环境复验仍待执行。
- 已保留 `flutter --version`、构建输出、启动进程与主窗口截图作为运行证据。
